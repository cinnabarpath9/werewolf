# 板子规则书

**产品共四张板子**（2026-10-30 作者拍板）：默认的 `eleven_wolfking`（11 人狼王版，**首夜无刀**）
+ **12 人预女猎白** + **常规 9 人屠城（暗牌）** + **6 人屠城（明牌）**。
其余内置板子（`eleven` / `eleven_standard` / `eleven_dream` / `eleven_guard`）**已退役**，
定义留在 `wolf/retired_boards.py` 供回归与题库复现历史机制，产品面板不列、`make_board` 也不认。
恢复办法请向维护者索取《板子备份_已删除》（随源码仓库提供，不在发布包里）。

> 口径声明：**本项目的规则以用户本人为准**。凡是与官方（网易《狼人杀》）不同的地方，
> 都在这里写明「本项目怎么算」。官方规则只作对照，不自动生效。

## 一、默认板子：`eleven_wolfking`（11 人狼王版）

| 项 | 内容 |
|---|---|
| 人数 | 11 |
| 狼 | **狼人 ×3 + 狼王 ×1** |
| 神职 | 预言家 ×1、女巫 ×1、**摄梦人 ×1**、**愚者 ×1** |
| 民牌 | **守墓人 ×1、养鸦人 ×1、幸运儿 ×1**（官方都是神牌，本项目当民牌用） |
| 警长 | **有**（11 人及以上有警长竞选；警徽 = 1.5 票） |
| 胜负 | **屠边**：狼杀光全部神职 或 全部村民 → 狼胜；狼全灭 → 好人胜 |
| 愚者（原白痴） | **既算神也算民**（两条边都要杀到他） |
| **首夜无刀** | **第 1 夜狼队/女巫/摄梦人都零调用**，整夜只跑一次预言家验人；女巫与摄梦人**从第 2 夜起**才行动 |
| **狼王** | **任何原因出局都能带走一名好人**（含**被毒**；**不含自爆——狼王不能自爆**）；**不能带狼队友**；带人公开指定 |
| **结算次序** | **死亡结算 → 狼王带人 → 再判屠边** |

### 这块板子相对上一版的三个改动（也是它的全部设计）

1. **4 狼 → 3 狼 + 1 狼王**：狼王是「死也要拖一个走」的牌，用来**补首夜无刀缺的那一刀**。
   只要他不是最后一个走，他死的那一下约等于**狼队多一刀**；但他**最后一个走时收益很窄**
   （必须精准带走某一边的最后一张才算值），所以狼队不能无脑护狼王。
2. **首夜无刀**：第一夜不结算狼刀，女巫不给药、**也不被告知刀口**，摄梦人不动手 ——
   整夜只有预言家一次验人（首夜调用数 **11 → 1**）。
3. **结算次序**：狼王的反扑**插在判胜负之前**，而且要**再判一次屠边**（双向）。
   好人把「最后一狼（狼王）」票出去、他临死带走某一边最后一张好人牌 ⇒ **照样算狼队屠边成功**。

### 为什么换（作者观察，已被三局真实思维链证实）

旧板子「首夜女巫能自救」把**银水变成了铁好**：狼「自刀骗药」即使成功也**吞不掉两瓶药**、
反而白送一狼 ⇒ **EV 为负** ⇒ 三局真实对局的狼队思维链里 **77 / 20 / 6 处**提到自刀、
**全部主动放弃**（原话：「自刀骗药这局先不用：女巫第一晚救不救五五开，白丢一匹狼太亏」）⇒
狼永远走「外置位中心开刀」 ⇒ **银水没人质疑、好人白拿一条确定信息**。

结论：这不是模型不会玩，是**机制给的 EV 就是负的** ⇒ 改机制（写打法书没用）。

### 连带影响（作者已确认的连锁）

- 首夜无刀 ⇒ **银水从第一夜挪到第二夜**；第 2 夜女巫手里有药 + 听完一轮发言 ⇒
  **自刀骗药的 EV 由负转正**（狼可以选「炸一个身份 + 自刀做身份」）；
- 第 2 夜同时有**女巫解药 + 摄梦 + 幸运儿守护**三个保护源 ⇒ **奶穿从边角规则变成主旋律**；
- 狼王「开枪即定死狼身份、队形露一片」 ⇒ 好人有动机**主动找狼王票**，
  狼队会让**小狼装狼王**骗票 ⇒ 骗/反骗成立。

### 本项目的规则改动（相对官方）

> 维护者注：自爆可整局关掉（`config.yaml` 的 `game.wolf_explode: false`）；
> 双爆轮若拿不到狼队回答（调用失败/超时），按「不继续自爆」处理 → 第二天恢复竞选。

| 摄梦 + 女巫解药 | （官方未写） | **奶穿：照样死**（用户 2026-10-09 改定） |

| 梦游者是否免疫毒 | 免疫夜间伤害（含毒） | **免疫**（用户确认） |
| 梦游者是否免疫枪 | （本项目板子无猎人） | **免疫**（用户确认，将来有猎人时按此口径） |
| 自摄连续两晚 | —— | **自己也会死**（用户确认） |
| **摄梦人死亡是否带走梦游者** | 官方：带走（连死） | **不带走**（2026-10-10 `6d8d7b4` **取消「连死」**，跟守卫一样） |
| 被连摄致死的梦游者能否开枪（有猎人时） | —— | **能开**（用户确认） |
| 要不要加「不能连续两晚摄同一人」 | —— | **不加** —— 用户原话：「摄梦就是为了平衡追刀的」 |
| 守墓人 / 养鸦人 | 官方是**神牌** | **降为民牌**（用户改定），能力不变 |
| 幸运儿 | 由**奇迹商人**赋予技能 | **不用奇迹商人**，技能直接在身上（一次性三选一；**第 1 夜不问**，第 2 夜起才问） |
| 守墓人的信息时机 | 夜里展示白天出局者信息 | **白天发言轮开始时**给他（零额外调用；夜里没有他的事） |
| 预言家是否上警 | 由玩家自己决定 | **锁定上警**（**本局开关 `game.seer_auto_run`，默认开**；不给他发上警决策调用）—— ⚠️ 只在**有警长竞选**的局里生效；关掉就照常问他 |
| 养鸦人（乌鸦）的技能时机 | 夜里暗中诅咒 | **白天放逐投票那一刻**临时决定，与投票同一次决策 |
| 「不能连续两晚诅咒同一玩家」 | 官方乌鸦的限制 | **本项目不采用**（作者口径：**可以连着几天咒同一个人**） |
| 被咒者的可见性 | （官方未写） | **投票结果里公开带「咒标」**，但**不公布是谁咒的** |
| 女巫自救 | 12 人场：全程不能自救 | **被刀那一夜可以自救**（⚠️ 首夜无刀的板子上她第一夜不行动，所以这条实际从第 2 夜开始生效） |
| 发言顺序（无警长） | 平安夜→随机；否则从出局者上家逆序 | **按座位号从小到大** |
| 发言顺序（有警长） | 警长选上家逆序/下家顺序 | 警长选**顺序/逆序**，且**两种都是警长最后发言** |
| 自曝时机 | 狼可自曝身份，立即终止白天流程，直接进夜，**无爆后发言/遗言** | **两个窗口**：上警后团队决策 + 自己的决策窗口（竞选/定方向/发言前）；竞选期间自曝 → **警徽流失** |
| 愚者 | （官方另有白痴板） | **双算 + 翻牌后不可被投**（投他按无效票记，不计票） |

### 11 人板专属：自爆改了两处（2026-11-03）

- **狼王不能自爆**：拿到狼王牌的人**不参与任何「要不要自爆」的决策**（省掉那一次调用）；
  狼王只靠**出局**那一口带人。
- **单狼自爆不吞警徽**：竞选**挂起**、当天到此为止；第二天白天先公布夜里可公开的信息
  （谁出局 / 平安夜），然后**剩下的狼再决策一次**要不要接着爆：
  - 再爆（**双狼自爆**）→ **警徽被吞**，本局没有警长，当天也就此结束；
  - 不爆 → **恢复竞选**：第一天已发过言的人不再重复，然后投票决定警徽归属。
- 其他板子保持原规则（单狼自爆即吞警徽；狼王能自爆——那几张板子没有狼王）。

## 二、另外三张可选板子（改 `config.yaml` 的 `game.board` 即切换）

| 板名 | 人数 | 构成 | 胜负 | 警长 |
|---|---|---|---|---|
| `twelve_standard` | 12 | 4 狼 + 预言家、女巫、**猎人**、**愚者** + 4 民 | **屠边**（愚者双算） | **有**（≥ 11 人） |
| `nine_all` | 9 | 3 狼 + 预言家、女巫、猎人 + 3 民 | **屠城** | 没有（< 11 人） |
| `six_all_reveal` | 6 | 2 狼 + 预言家、女巫 + 2 民 | **屠城** + **出局亮身份** | 没有（< 11 人） |

### 2.1 屠城（`nine_all` / `six_all_reveal`）

**狼人必须杀光所有好人**才算赢：杀光神职**不算**、杀光村民**也不算**
（这是它和默认板子「屠边」唯一的胜负差异）。好人照样是放逐全部狼人就赢。

> 引擎的「狼人控场」判定照常生效：存活狼数 ≥ 存活好人数、且好人已无夜间反击能力
> （毒药 / 猎人 / 摄梦人 / 没用掉的幸运儿）⇒ 判狼胜 —— 那本来就是屠城的结果，
> 只是提前结算、不再磨残局。若好人手里还有能弄死狼的牌，会照常给最后的机会。

### 2.2 出局亮身份（`six_all_reveal` 专属）

**任何人出局时当场公开身份牌**：任何夜间死亡（被刀、被毒）、白天被放逐，全都亮
（公告写「X号 出局，亮明身份：【某某】」）。
**死因仍然不公示**：公告照旧写「不公布死因」，你只知道"他是什么牌"，不知道"他怎么死的"。
手机顶栏的已出局座位也会标出亮出的身份。

> 这张板子的设计意图：6 人局轮次极短、信息极少，出局亮身份让**每一次死亡都产出一条确定的
> 公开信息**，把博弈从"猜谁是狼"变成"用死人的牌反推活人的谎"。它跟暗牌局的打法**不能混用**。

> ⚠️ 切板子会**换掉模型读到的规则片段**（`规则书.md` 按板子组装：`firstnight` 那段
> **只有首夜无刀的板子发**；`reveal` 那段**只有出局亮身份的板子发**；
> `role:wolf_king` 只有狼王版发）。换板后跑一次 `python tests/check_rules_per_board.py` 与全量回归。

## 四、开新板子的检查清单（别漏项）

1. `wolf/roles.py` 的 `BUILTIN_BOARDS` 里加板子定义（角色 key 必须在 `ROLES` 里有定义）；
   板子级的**新开关**（如 `first_night_quiet`）要同时加进 `BoardDef`、`_b()`、`make_board()`。
2. `content/01_规则书.md` 里给**每个新角色**补 `<!-- frag:role:<key>:begin --> … end -->`；
   **板子级的规则**（如首夜无刀）另开一段条件片段（`frag:firstnight`），
   并在 `wolf/rules.py::compose` 里按板子开关决定发不发
   （⚠️ 千万别写进 `frag:core`：core 是所有板子共用的，会发错对象）。
3. `content/04_角色书.md` 里补 `<!-- frag:role:<key> -->` 章节（不给的话这个角色只能读通用章）。
   ⚠️ 如果新角色属于**已有阵营角色**（例如狼王之于狼人），记得在
   `wolf/tabletalk.py::ROLE_EXTRA_FRAGS` 里登记**角色章继承**，否则它拿不到那一整章战术。
4. **手写的名字表**要一起补：`wolf/context.py::_CLAIM_ALIASES`（「我是X」识别）、
   `wolf/persona.py::RISKY_WORDS`、`server.py::board_options.tag_of`（板子短标签）。
   跑 `python tests/check_role_names.py` 会自动检查这几处。
5. 引擎里实现技能（夜晚步骤 + 结算 + 私有提示 + 台账），并**给它写剧本回归**
   （参考 `tests/t_wolf_king.py`：任何死因带人 / 不能带队友 / 自爆带人 / 结算次序，一条一条真跑）。
6. `tests/check_rules_per_board.py` 的 `MUST` 表里加这个板子的关键规则字面判据。
7. 跑 `--quick` 与全量回归；把新板子写进本文档与 `README.md`。
