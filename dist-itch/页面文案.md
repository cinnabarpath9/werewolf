## Description（正文）

```
一个人，也能凑齐一桌。

狼人杀最难约的从来不是规则，是凑齐一桌愿意演的人。
这里不给你「匹配陌生人」，也不给你「看一段录好的对话」——
每一局都是模型现场生成：你发言、你投票、你被查杀、你被悍跳，都按真实规则结算。

■ 真规则
四张内置板子（11 人狼王版 / 12 人标准 / 9 人屠城 / 6 人明牌）、警长竞选、遗言、PK、自爆、奶穿……
规则书是唯一口径，模型拿到的包也按它裁。

■ 真模型
每个座位可以单独选平台与模型（DeepSeek / GLM / MiniMax / Claude / Gemini 等），
温度、思考档、token 上限都能配；也可以一个座位一个模型混搭。

■ 真隔离
每个 AI 只看到「自己该看到的那一份」——公开信息、狼队夜间讨论、自己的私有笔记；
浏览器端不持有过滤规则，夜里也不会在手机上泄露「几号在思考」。

■ 完整复盘
每次调用都留痕：当时的提示包、完整思维链、token、耗时。打完能逐手看它为什么那么说。

■ 一台主机、多人加入
朋友用浏览器加入、各自坐一个座位；只想看 AI 打，就点「观战（全 AI）」。

■ 不花钱也能玩
大厅点「离线演练」：不填任何 key、不调用任何模型，规则/界面/复盘全部可用。

────────────────────────
关于模型费用（请先读）

本游戏不代收任何 API 费用，也不内置额度：
· 想用真模型：进「设置 → 模型 API」填你自己的 key，费用由你的模型平台按 token 计；
· 不想花钱：用「离线演练」，先把规则和界面玩明白；
· 我们不会要求你在站外购买任何东西。

────────────────────────
怎么玩

1. 下载 → 解压 → 双击 werewolf.exe（Windows 10/11，免装 Python）；
2. 浏览器自动打开（黑窗口里会打印本机与同一 Wi-Fi 的地址）；
3. 想和朋友一起：房主开着客户端，朋友用黑窗口里的局域网地址打开浏览器，用「联机码」加入；
4. 首次运行如果 Windows 弹「已保护你的电脑/未知发布者」：点「更多信息」→「仍要运行」
   （没有代码签名证书的常见提示，可在 VirusTotal 自查）。

────────────────────────
配置要求

· Windows 10/11（64 位），约 120MB 磁盘，无需显卡；
· 真模型对局需要联网；离线演练完全离线可玩；
· 建议 8GB 内存（模型在云端跑，本地只跑规则与页面）。

────────────────────────
已知边界（诚实写）

· 纯单人视角，没有陌生人匹配、没有语音房；
· 语音（TTS/ASR）需要额外配置服务，默认关闭；
· 模型会犯错：时间线、记错票、话说太满——这既是它的毛病，也是这游戏的一部分；
· 首发只做「单人 + 同机/局域网」，联网陌生人局不在这一版。

────────────────────────
许可

源码可见 + 个人非商业使用；本客户端由作者发布，可免费下载游玩。
商用 / 二次分发需作者书面授权（详见仓库 LICENSE）。
```
