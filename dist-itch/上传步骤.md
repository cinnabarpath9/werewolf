# itch.io 上传步骤（照着点，10 分钟）

> 前置：你有 itch 账号（没有就注册一个，免费）。本目录里的文件已经齐了。

## 1. 建项目

1. 打开 <https://itch.io/game/new>；
2. **Title**：`AI 狼人杀 — 你坐一席，剩下的交给 AI`
3. **Project URL**：建议 `ai-werewolf-cn`（itch 会给你 `xxx.itch.io/ai-werewolf-cn`）；
4. **Short description / tagline**：从 `页面文案.md` 的「一句话」复制；
5. **Classification**：Game；**Release status**：Released；
6. **Made with**：可填 `Python`、`JavaScript`（可不填）；
7. **Platforms**：只勾 **Windows**。

## 2. 传封面和截图

1. **Cover image**：上传 `cover-630x500.png`；
2. **Screenshots**：按顺序上传 `screenshots/01-lobby.png` … `06-settings.png`；
3. 每张图可以填 alt 文本（`页面文案.md` 里给了 6 条）。

## 3. 写正文

把 `页面文案.md` 的「Description（正文）」整段粘进 **Description**。
（里面已经写了"自备 key / 离线演练不花钱 / 已知边界"，别删这几段——这是差评的主要来源，提前说清。）

## 4. 传游戏包

1. **Uploads** → **Upload files** → 选 `werewolf-1.2.23-win64-itch.zip`（51.6 MB）；
2. 上传完勾 **"This file will be played on Windows"**；
3. 建议把压缩包标记为 **"Windows"** 平台、**"Downloadable"**。

## 5. 定价

- 推荐 **No payments**（纯免费，最省心）；
- 以后想收自愿打赏再改成 **Pay what you want**（最低价可以设 0）。

## 6. 标签

在 **Tags** 里填（最多 10 个）：

```
werewolf, mafia, ai, llm, text-based, singleplayer, multiplayer, local-multiplayer, deduction, experimental
```

## 7. 发布前自查（30 秒）

- [ ] 页面里能清楚看到「**离线演练不花钱**」和「**真模型要自己的 key**」；
- [ ] 平台只勾了 Windows；
- [ ] 上传的文件就是 `werewolf-1.2.23-win64-itch.zip`（不是旧版 1.2.22）；
- [ ] 封面是 630×500；
- [ ] 至少 4 张截图；
- [ ] 正文里有「已知边界」那一段。

## 8. 发布后

- 把链接发我，我把它加进 README / 部署说明 / 交接（"下载"那一栏）；
- 有人反馈"打不开/没 key 不会用"，先看是不是这两个：
  1. 没解压就双击（必须解压整个文件夹再跑 exe）；
  2. 以为自带额度（正文已写，但可以再加一句到 `怎么玩.txt`）。

## 以后更新版本

1. 重新打客户端：`python tools/build_exe.py --zip`；
2. itch 项目页 → **Uploads** → 传新 zip → 在文件列表里把新文件设为默认；
3. 版本号变了记得同步 `页面文案.md` 里的文件名。
